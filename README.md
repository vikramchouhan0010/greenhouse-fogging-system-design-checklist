# Greenhouse fogging system: design and quotation checklist

Use this list when you plan or order a fogging (misting) system for a greenhouse or polyhouse bay.

## Size the bay
- [ ] Bay length and width measured inside the frame
- [ ] Line spacing and nozzle spacing written down (for example 3 m x 3 m)
- [ ] Lines = width / line spacing; heads per line = length / nozzle spacing
- [ ] Example: a 40 m x 30 m bay at 3 m x 3 m is 10 lines of 14 heads = 140 heads (about 111 heads per 1,000 m2)

## Flow and zones
- [ ] Discharge of one head at working pressure taken from the supplier quotation (do not assume)
- [ ] Total flow = heads x discharge of one head
- [ ] Zones chosen so the pump only runs one zone at a time, each on its own valve
- [ ] Pulse timing set on the controller (short on, longer off), not continuous running

## Filtration and fittings
- [ ] Filtration upstream of the nozzles (120 mesh is listed for the BLUSTAL 4-Way Fog Nozzle)
- [ ] Working pressure matched to the nozzle (4.0 kg/cm2 listed for the 4-Way Fog Nozzle, 65 micron average droplet)
- [ ] One drop per nozzle: supply line, stabiliser weight, then the nozzle; anti-drip fitting where dripping on the crop is a risk

## Send the supplier
Bay size, grid, number of zones, water source and quality, pump available, crop and the climate problem you are solving.
